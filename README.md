# NeverGate Launcher

NeverGate Launcher ist ein Launcher-Projekt im Minecraft-Bereich. Der bislang dokumentierte Entwicklungsstand umfasst **Alpha 6 mit gemeldeter Forge-Zuordnung**.

## Stand

**Dokumentationsstand: 1. November 2026.** Alpha 6 ist ein historisch gemeldeter Zwischenstand. Ein neuer, vollständig verifizierter und authentifizierter Windows-Start ist noch nicht nachgewiesen. Auch die erforderliche API-Freigabe ist als offen dokumentiert.

Das ist **keine Ankündigung einer fertigen oder allgemein freigegebenen Version**.
