# Leitfaden für die nächste Abnahme

Dies ist eine Prüfliste für einen bereitgestellten Testbuild, keine Installationsanleitung für einen hier veröffentlichten Download.

## Voraussetzungen

- Den konkreten Testbuild und seine Version eindeutig festhalten.
- Einen vorgesehenen Windows-Testrechner verwenden.
- Den tatsächlichen Stand der API-Freigabe klären.
- Zugangsdaten ausschließlich im vorgesehenen Anmeldeablauf eingeben; nicht in Fehlerberichte oder öffentliche Dateien kopieren.
- Vorhandene Minecraft-Daten sichern und Tests möglichst getrennt von produktiv genutzten Installationen durchführen.

## Prüfschritte

1. Startet der Launcher auf Windows ohne unerwarteten Fehler?
2. Funktioniert die vorgesehene Anmeldung tatsächlich?
3. Bleibt die für den Test vorgesehene Minecraft-/Forge-Zuordnung korrekt?
4. Startet das zugeordnete Spiel nach erfolgreicher Anmeldung?
5. Bleiben bestehende Installationen und Daten unverändert, soweit keine Änderung beabsichtigt ist?
6. Lässt sich der Ablauf nach einem Neustart wiederholen?
7. Werden fehlende Voraussetzungen oder eine fehlgeschlagene Anmeldung verständlich angezeigt?

## Ergebnis festhalten

Für jeden Punkt „bestanden“, „fehlgeschlagen“ oder „nicht geprüft“ angeben. Buildversion, Windows-Version und die relevanten Schritte ergänzen. Einen insgesamt erfolgreichen Start erst dann melden, wenn Anmeldung und tatsächlicher Spielstart nachgewiesen sind.

Vor dem Teilen von Screenshots oder Protokollen Tokens, Kontodaten und persönliche Pfade entfernen.
